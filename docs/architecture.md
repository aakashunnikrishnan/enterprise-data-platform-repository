# Enterprise Real-Time Data Platform Architecture

## 1. Overview

The Enterprise Real-Time Data Platform is a cloud-native data platform designed to ingest, process, store, and analyze high-volume real-time retail events.

The platform combines:

- Microsoft Fabric
- Azure Event Hubs
- Kafka-compatible event streaming
- Azure Kubernetes Service (AKS)
- Delta Lake
- Apache Spark
- Terraform
- GitHub Actions
- Azure Monitor
- Prometheus
- Grafana
- Power BI

The architecture follows an event-driven and lakehouse-oriented design.

---

## 2. Business Scenario

The platform simulates a large-scale retail organization processing events generated by:

- Web applications
- Mobile applications
- Point-of-sale systems
- Inventory systems
- Payment systems

Example events include:

- Order created
- Order updated
- Order cancelled
- Payment completed
- Inventory updated
- Product price changed
- Customer activity
- Fraud alerts

The platform must support both real-time operational processing and analytical workloads.
